# 💬 WhatsApp Clone

A modern **WhatsApp Clone Android application** built with **Kotlin, Jetpack Compose, MVVM, and Firebase**.

## ✨ Features

* 🔐 Firebase Authentication
* 💬 Real-time Messaging
* 👤 User Management
* 🟢 Online/Offline Status
* ⏱️ Message Timestamps
* 🎨 Modern Material 3 UI
* 🔄 Real-time Firestore Sync

## 🛠️ Tech Stack

* Kotlin
* Jetpack Compose
* Material 3
* MVVM Architecture
* Firebase Authentication
* Firebase Firestore
* Coroutines & StateFlow
* Navigation Compose
